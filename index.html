yad

Yet Another Datepicker: dependency-free, with a jQuery UI compatible API.

Default popup

new Yad('#basic')

Dropdowns, button panel, week numbers

{ changeMonth: true, changeYear: true, showButtonPanel: true, showWeek: true, firstDay: 1 }

Restricted range: today to +2 months, no weekends

{ minDate: 0, maxDate: '+2m', beforeShowDay: Yad.noWeekends }

Trigger button, altField, German locale

alt field:

{ ...Yad.regional.de, showOn: 'both', buttonText: '📅', altField: '#alt', altFormat: 'yy-mm-dd' }

French locale

{ ...Yad.regional.fr, changeMonth: true, changeYear: true, showButtonPanel: true }

Three months

{ numberOfMonths: 3, showCurrentAtPos: 1, showOtherMonths: true }
